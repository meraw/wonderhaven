# Wonderhaven: The Lost Isles

A cozy 3D fantasy kingdom-building adventure: explore colourful islands, help quirky villagers, gather materials and build creative solutions with the magical Starforge Tool.

The game is the **Godot 4** project in `godot/`: see `godot/README.md` to open and play it.

## The original browser prototype (frozen)

The Three.js version below is kept as it was and no longer updated.

```bash
npm install
npm run dev
```

Then open http://localhost:5174. `npm run build` writes a static copy to `dist/`.

## Controls

WASD move · drag mouse / Q Z camera · wheel zoom · E interact · Space hop · Shift run

## Develop

`npm test` runs the browser version's rule and data tests (no browser). See `CLAUDE.md` and `docs/STATUS.md`.
